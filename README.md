# RailSpeed ระบบจองตั๋วรถไฟออนไลน์ (Django)

เว็บจองตั๋วรถไฟที่ออกแบบหน้าตาด้วย Google Stitch และเชื่อมกับฐานข้อมูลจริงทุกปุ่ม
ที่นั่งที่ขึ้นว่า "จองแล้ว" มาจากการจองในฐานข้อมูล แอดมินแก้ข้อมูลได้จริง มีผู้ช่วย AI ที่อ่านข้อมูลจากระบบ และชำระเงินด้วย QR พร้อมเพย์ที่โอนได้จริง

---

## 1. ติดตั้งและรัน

ต้องมี **Python 3.10 ขึ้นไป** (ตรวจด้วย `python --version`)
ถ้ายังไม่มี ดาวน์โหลดที่ https://www.python.org/downloads/ (Windows: ติ๊ก "Add Python to PATH" ตอนติดตั้ง)

**วิธีง่ายสุด** ดับเบิลคลิกไฟล์:
- Windows: `run_windows.bat`
- macOS / Linux: `./run_mac_linux.sh`

ครั้งแรกสคริปต์จะสร้าง virtual environment, ติดตั้ง Django, สร้างฐานข้อมูล และใส่ข้อมูลตัวอย่างให้เอง
จากนั้นเปิดเบราว์เซอร์ที่ **http://127.0.0.1:8000**

**รันเองทีละคำสั่ง**
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed --reset     # ล้างข้อมูลแล้วสร้างข้อมูลตัวอย่างใหม่ (วันที่อิงจากวันนี้)
python manage.py runserver
```

ต้องต่ออินเทอร์เน็ต เพราะหน้าเว็บโหลด Tailwind, ฟอนต์, ปฏิทิน และตัวสร้าง QR จาก CDN และผู้ช่วย AI เรียก API ออนไลน์

## 3. ตั้งค่าผู้ช่วย AI และ QR พร้อมเพย์ (ไฟล์ `.env`)

1. คัดลอกไฟล์ `.env.example` แล้วเปลี่ยนชื่อเป็น **`.env`** (อยู่โฟลเดอร์เดียวกับ `manage.py`)
   Windows: เปิด File Explorer → View → ติ๊ก **File name extensions** เพื่อให้แน่ใจว่าชื่อไม่ใช่ `.env.txt`
2. เปิดด้วย Notepad แล้วใส่ค่าของคุณ
3. ปิดเซิร์ฟเวอร์ (Ctrl+C) แล้วรันใหม่ ระบบอ่านไฟล์ `.env` ตอนเริ่มเท่านั้น

ตัวอย่างไฟล์ `.env`
```dotenv
# ---- ผู้ช่วย AI ----
OPENROUTER_API_KEY=sk-or-v1-คีย์ของคุณ
OPENROUTER_MODELS=google/gemma-4-31b-it:free,google/gemma-4-26b-a4b-it:free,nvidia/nemotron-3-super-120b-a12b:free,thinkingmachines/inkling:free
RAILSPEED_CHAT_ALLOW_TRAVEL=1
RAILSPEED_CHAT_LIMIT=20

# ---- QR พร้อมเพย์ ----
RAILSPEED_PROMPTPAY_ID=เบอร์มือถือ-หรือ-เลขพร้อมเพย์ของคุณ
RAILSPEED_PROMPTPAY_NAME=ชื่อที่แสดงใต้ QR
RAILSPEED_PAY_DIVISOR=100
```

| ค่า | ใช้ทำอะไร |
|---|---|
| `OPENROUTER_API_KEY` | คีย์จาก https://openrouter.ai/keys ใช้โมเดลฟรีได้โดยไม่ต้องเติมเงิน |
| `OPENROUTER_MODELS` | รายชื่อโมเดล คั่นด้วยจุลภาค ไม่เว้นวรรค ระบบลองทีละตัว ถ้าตัวแรกไม่ว่างจะใช้ตัวถัดไป ทุกตัวต้องลงท้าย `:free` ดูรายชื่อล่าสุดที่ https://openrouter.ai/models?q=free แล้วกดปุ่มคัดลอก slug ใต้ชื่อโมเดล |
| `RAILSPEED_CHAT_ALLOW_TRAVEL` | `1` = ตอบเรื่องที่เที่ยวใกล้สถานีปลายทางได้ด้วย · `0` = ตอบเฉพาะเรื่องตั๋วและการใช้งานเว็บ |
| `RAILSPEED_CHAT_LIMIT` | จำนวนข้อความแชทต่อชั่วโมงต่อผู้ใช้ (ค่าเริ่มต้น 20) |
| `ANTHROPIC_API_KEY`, `CLAUDE_MODEL` | ทางเลือก: ใช้ Claude แทน (ใช้เมื่อไม่ได้ใส่ `OPENROUTER_API_KEY`) |
| `RAILSPEED_PROMPTPAY_ID` | เบอร์มือถือ 10 หลัก, เลขบัตรประชาชน 13 หลัก หรือเลขพร้อมเพย์ 15 หลัก (เช่นเลขที่อ้างอิงใต้ QR รับเงินของแอป K+) **ห้ามใส่เลขบัญชีธนาคาร** |
| `RAILSPEED_PROMPTPAY_NAME` | ชื่อที่แสดงใต้ QR บนเว็บ (ชื่อที่ขึ้นในแอปธนาคารตอนสแกนคือชื่อบัญชีจริงเสมอ) |
| `RAILSPEED_PAY_DIVISOR` | โหมดสาธิต: ยอดใน QR = ราคาตั๋ว ÷ ค่านี้ เช่น `100` ตั๋ว 441 บาทจะโอนจริง 4.41 บาท · `1` = ราคาจริง |
| `RAILSPEED_HOLD_MINUTES` | เวลากันที่นั่งระหว่างชำระเงิน (ค่าเริ่มต้น 15 นาที) |
| `DJANGO_SECRET_KEY`, `DJANGO_DEBUG` | ค่าสำหรับพัฒนา ต้องตั้งใหม่ถ้าจะเอาขึ้นเซิร์ฟเวอร์จริง |

**ความปลอดภัย:** ไฟล์ `.env` มี API key ของคุณ **อย่าส่งให้คนอื่น อย่าใส่ใน zip ที่ส่งงาน และอย่าอัปโหลดขึ้น GitHub** ถ้าคีย์หลุด ให้ลบที่ openrouter.ai/keys แล้วสร้างใหม่ทันที

## 4. ผู้ช่วย AI

กดปุ่ม **"ถามผู้ช่วย"** มุมขวาล่างของทุกหน้าฝั่งผู้ใช้

**ตอบได้ โดยอิงข้อมูลจริงจากฐานข้อมูลที่แนบไปกับทุกคำถาม**
- วิธีจองตั๋ว ขั้นตอนชำระเงิน สถานะการจอง และปัญหาการใช้งานเบื้องต้น
- ราคาทุกประเภทตู้ (ถ้าแอดมินแก้ราคา ผู้ช่วยรู้ทันที)
- รอบเดินทาง 7 วันข้างหน้า พร้อมเวลาและจำนวนที่นั่ง/เตียงว่างจริง
- การจองของ**ผู้ใช้ที่ล็อกอินอยู่เท่านั้น** (ไม่เห็นการจองของคนอื่น)
- ที่เที่ยวใกล้สถานีปลายทาง (ปิดได้ด้วย `RAILSPEED_CHAT_ALLOW_TRAVEL=0`) ส่วนนี้ใช้ความรู้ทั่วไปของโมเดล อาจไม่แม่นยำ 100%

**ไม่ตอบเรื่องอื่น** เช่น การบ้าน เขียนโค้ด ข่าว จะตอบว่า "ขออภัยครับ ผมตอบได้เฉพาะเรื่องการจองตั๋วรถไฟและการใช้งานเว็บ RailSpeed เท่านั้น"
ปัญหาที่ต้องให้แอดมินแก้ (เช่น โอนแล้วสถานะไม่เปลี่ยน) จะแนะนำให้ส่งข้อความที่หน้า "ติดต่อเรา"

**ตัวอย่างคำถามสำหรับสาธิต** (ล็อกอินเป็น `user01@example.com`)
- "การจองของฉันยืนยันหรือยัง" → แล้วให้แอดมินกดยืนยัน แล้วถามซ้ำ คำตอบจะเปลี่ยนทันที
- "พรุ่งนี้ไปเชียงใหม่มีรอบไหนบ้าง ตู้นอนยังว่างไหม"
- "ตู้นอนชั้น 2 เตียงบนราคาเท่าไหร่"

**ข้อจำกัดของโมเดลฟรี (OpenRouter)**
- ประมาณ 20 ข้อความต่อนาที และ 50 ข้อความต่อวันต่อบัญชี (ถ้าเคยเติมเงินรวม 10 ดอลลาร์จะได้ 1,000 ต่อวัน) **วันนำเสนออย่าทดสอบจนโควตาหมด**
- ช่วงคนใช้เยอะ โมเดลฟรีอาจไม่ว่าง ใส่หลายโมเดลไว้ใน `OPENROUTER_MODELS` เพื่อสำรอง
- โมเดลฟรีถูกถอดได้ตลอด ถ้าขึ้น "ไม่พบโมเดล" ให้เลือกตัวใหม่จากหน้า models
- การสั่งให้ AI ตอบเฉพาะเรื่องเป็นการสั่งด้วยข้อความ ไม่การันตี 100% ถ้าพยายามหลอกหนักๆ อาจหลุดได้บ้าง

**ถ้าแชทขึ้นข้อผิดพลาด** ระบบจะบอกสาเหตุเป็นภาษาไทย และมีบรรทัด `[รายละเอียดสำหรับผู้พัฒนา]` แสดงข้อความจริงจาก API

| ข้อความ | แก้ยังไง |
|---|---|
| ยังไม่ได้ตั้งค่า API key | ไฟล์ไม่ได้ชื่อ `.env` จริง อยู่ผิดโฟลเดอร์ หรือยังไม่ได้รันเซิร์ฟเวอร์ใหม่ |
| API key ไม่ถูกต้อง | คัดลอกคีย์ไม่ครบ หรือมีช่องว่างเกิน |
| ไม่พบโมเดล | สะกด slug ผิด หรือโมเดลไม่ฟรีแล้ว · ตรวจ openrouter.ai/settings/privacy ว่าเปิดให้ใช้ free endpoints |
| โมเดลฟรีทุกตัวไม่ว่าง | รอสักครู่แล้วลองใหม่ หรือเพิ่มโมเดลสำรอง |

## 5. ชำระเงินด้วย QR พร้อมเพย์

- หน้าชำระเงินสร้าง **QR พร้อมเพย์มาตรฐาน (Thai QR Payment) พร้อมฝังยอดเงิน** สแกนด้วยแอปธนาคารไหนก็ได้ ไม่ต้องพิมพ์ยอดเอง
- ผู้ใช้โอนแล้ว**อัปโหลดสลิป** (JPG/PNG/WEBP/PDF ไม่เกิน 5MB) สถานะเปลี่ยนเป็น "รอยืนยัน"
- แอดมินเปิดดูสลิปในหน้า "การจอง" แล้วกด**ยืนยัน** ตั๋วของผู้ใช้จะขึ้น QR สำหรับขึ้นรถทันที
- ที่นั่งถูกกันไว้ 15 นาทีระหว่างชำระเงิน มีตัวนับถอยหลัง หมดเวลาแล้วคืนที่นั่งให้คนอื่นอัตโนมัติ

**โหมดสาธิตโอนเงินจริงยอดน้อย:** ตั้ง `RAILSPEED_PAY_DIVISOR=100` ราคาในเว็บ ตั๋ว และหน้าแอดมินยังเป็นราคาเต็ม แต่ยอดใน QR จะหาร 100 (441 บาท → โอน 4.41 บาท) หน้าชำระเงินมีป้าย "โหมดสาธิต" บอกชัดเจน

**วิธีทดสอบ QR:** จองจนถึงหน้าชำระเงิน → สแกนด้วยแอปธนาคาร → ต้องขึ้นชื่อบัญชีของคุณและยอดตรงกับหน้าเว็บ

**ข้อจำกัด:** เว็บไม่รู้เองว่าเงินเข้าแล้ว แอดมินต้องดูสลิปแล้วกดยืนยัน (การตรวจเงินอัตโนมัติต้องใช้ API ธนาคารหรือบริการตรวจสลิปแบบเสียเงิน)

## 6. ข้อมูลตัวอย่างจาก `seed`

- สถานี 10 แห่ง, ขบวน 6 ขบวน ได้แก่ EXP 9, SPR 13 และ NT 7 (ไปเชียงใหม่), EXP 10 (กลับกรุงเทพ), SPR 43 (ไปหัวหิน), EXP 21 (ไปอุบลฯ) ทุกขบวนวิ่งทุกวัน ตั้งแต่ 5 วันก่อนถึง 30 วันข้างหน้า
- ประเภทตู้ 4 แบบ ผัง 3 แบบ

| ประเภทตู้ | ผัง | ราคา |
|---|---|---|
| นั่งธรรมดา | 2+2, 8 แถว 32 ที่นั่ง | 441 |
| นั่งปรับอากาศ ชั้น 1 | 2+2, 8 แถว 32 ที่นั่ง | 750 |
| นอนชั้น 2 | 6 ล็อก ซ้าย/ขวา 24 เตียง | ล่าง 900 · บน 800 |
| นอนชั้น 1 (ห้องคู่) | 6 ห้อง 12 เตียง | ล่าง 1,500 · บน 1,400 |

- การจองจริง 18 รายการของผู้ใช้ 10 คน มีทั้ง รอยืนยัน (มีสลิป), ยืนยันแล้ว, ยกเลิก และการเดินทางที่ผ่านไปแล้ว
- **รอบที่คนจองเยอะที่สุด: EXP 9 กรุงเทพอภิวัฒน์ → เชียงใหม่ ในอีก 7 วัน** เปิดผังจะเห็นที่นั่งที่จองแล้วกระจายอยู่ทุกตู้
- ข้อความจากหน้าติดต่อเรา 2 ข้อความ

## 7. ลำดับการสาธิต (แนะนำ)

1. ล็อกอิน `test@railspeed.th` → หน้าหลัก กดช่องวันที่เพื่อเลือกจากปฏิทิน → เลือก กรุงเทพอภิวัฒน์ → เชียงใหม่ วันอีก 7 วัน → ค้นหา
2. เลือก EXP 9 → สลับดูตู้ 1-5 (ตู้นั่ง / ตู้นอนชั้น 2 / ห้องคู่ชั้น 1) ช่องสีเทาคือที่นั่งที่มีคนจองจริง → เลือก 1-4 ที่ → ยืนยัน
3. กรอกข้อมูลผู้โดยสาร (เลขบัตร 13 หลัก หรือกด "ใช้ข้อมูลของฉัน")
4. หน้าชำระเงิน → สแกน QR โอนจริง (โหมดสาธิตยอดหาร 100) → อัปโหลดสลิป
5. แอดมิน (อีกหน้าต่าง) → การจอง → ดูสลิป → ยืนยัน
6. ผู้ใช้ → การจองของฉัน → ดูรายละเอียด ตั๋วมี QR และพิมพ์ได้
7. ถามผู้ช่วย AI ว่า "การจองของฉันยืนยันหรือยัง" แล้วถามเรื่องนอกหัวข้อ ให้เห็นว่าระบบปฏิเสธ
8. แอดมินลองแก้ราคา เพิ่มตู้ หรือย้ายที่นั่งผู้โดยสาร แล้วกลับไปดูฝั่งผู้ใช้ว่าเปลี่ยนตาม
9. ลองให้ผู้ใช้สองคนจองที่นั่งเดียวกัน ระบบจะไม่ยอม (กันจองซ้ำที่ระดับฐานข้อมูล)

## 8. ฟีเจอร์ทั้งหมด

**ผู้ใช้**
- ค้นหาเที่ยวรถ: เลือกวันจากปฏิทินภาษาไทย (วันนี้ถึงอีก 30 วัน), เรียงตามเวลา/ราคา, เลื่อนวันก่อน/ถัดไป, แสดงที่นั่งและเตียงว่างจริง
- เลือกที่นั่ง 3 ผังตามประเภทตู้ สลับตู้โดยไม่เสียที่นั่งที่เลือกไว้ สูงสุด 4 ที่
- กันที่นั่ง 15 นาที และคืนที่นั่งอัตโนมัติเมื่อหมดเวลา
- ข้อมูลผู้โดยสาร ตรวจเลขบัตร 13 หลักและเบอร์โทร
- ชำระเงินด้วย QR พร้อมเพย์ + อัปโหลดสลิป
- ตั๋วพร้อม QR หนึ่งใบต่อที่นั่ง และพิมพ์ได้
- การจองของฉัน 3 แท็บ (กำลังจะเดินทาง / เสร็จสิ้น / ยกเลิก) และยกเลิกการจองได้
- โปรไฟล์ เปลี่ยนรหัสผ่าน สมัครสมาชิก
- ติดต่อแอดมิน
- ผู้ช่วย AI ที่อ่านข้อมูลจริง
- โหมดมืด/สว่าง (จำค่าที่เลือกไว้) และเมนูสำหรับมือถือ

**แอดมิน (`/manage/`)**
- แดชบอร์ด: การจองวันนี้, รายได้, ที่นั่งที่จองแล้ว, สลิปรอตรวจ, กราฟ 7 วัน, การจองล่าสุด
- การจอง: ค้นหา, กรองสถานะ, ดูสลิป, ยืนยัน, ยกเลิก, แก้ไข (ชื่อ/เบอร์ผู้โดยสาร, ย้ายไปที่นั่งที่ว่าง, สถานะ, บันทึกแอดมิน)
- สถานี / ขบวนรถ / รอบเดินทาง / ประเภทตู้และราคา: เพิ่ม แก้ ลบ (ลบไม่ได้ถ้ายังมีข้อมูลอ้างอิง)
- ตู้ของขบวน: เพิ่มตู้แล้วสร้างที่นั่งตามผังอัตโนมัติ, ลบตู้ที่ยังไม่เคยมีการจอง
- ผู้ใช้: ค้นหา, ระงับ/ปลดระงับ (ผู้ใช้ที่ถูกระงับล็อกอินไม่ได้)
- แอดมิน: เพิ่ม/ลบผู้ดูแล
- ข้อความจากผู้ใช้: อ่านเพิ่มเติม, ทำเครื่องหมายอ่านแล้ว, กดอีเมลเพื่อตอบกลับ

## 9. REST API

เว็บมี REST API ที่สร้างด้วย **Django REST Framework** อยู่ที่ `/api/` เปิด http://127.0.0.1:8000/api/ ในเบราว์เซอร์จะเห็นหน้า **Browsable API** ที่กดดูและลองเรียกได้ทุก endpoint

**ติดตั้งครั้งแรก (หลังอัปเดตโค้ด):**

```bash
pip install -r requirements.txt
python manage.py migrate
```

**การยืนยันตัวตน:** ใช้ได้ 2 แบบ

- ล็อกอินในเว็บตามปกติ แล้วเปิด `/api/` ในเบราว์เซอร์เดียวกัน (session)
- ขอ token ด้วย `POST /api/auth/token/` แล้วส่ง header `Authorization: Token <token>` ทุกคำขอ

| Method | Endpoint | ใครใช้ได้ | ทำอะไร |
| --- | --- | --- | --- |
| POST | `/api/auth/token/` | ทุกคน | ส่ง `email`, `password` ได้ token กลับมา |
| GET | `/api/me/` | ล็อกอินแล้ว | ข้อมูลผู้ใช้และจำนวนการจองแยกตามสถานะ |
| GET | `/api/stations/` | ทุกคน | รายชื่อสถานี |
| GET | `/api/car-types/` | ทุกคน | ประเภทตู้และราคา |
| GET | `/api/trains/` | ทุกคน | ขบวนรถพร้อมตู้ |
| GET | `/api/schedules/?from=&to=&date=&sort=` | ทุกคน | ค้นหารอบเดินทาง พร้อมที่นั่ง/เตียงว่างและราคาเริ่มต้น |
| GET | `/api/schedules/{id}/seats/` | ทุกคน | ผังที่นั่งทุกตู้ (`taken: true` = มีคนจองแล้ว) |
| GET | `/api/bookings/` | ล็อกอินแล้ว | การจองของฉัน (แอดมินเห็นทั้งหมด กรองด้วย `?status=pending`) |
| POST | `/api/bookings/` | ล็อกอินแล้ว | จองและกันที่นั่ง `{"schedule": id, "seats": [id, ...]}` |
| POST | `/api/bookings/{id}/passengers/` | เจ้าของ | ใส่ข้อมูลผู้โดยสาร `[{"id", "passenger_name", "id_card", "phone"}]` |
| POST | `/api/bookings/{id}/slip/` | เจ้าของ | อัปโหลดสลิป (multipart ช่อง `slip`) สถานะเป็นรอยืนยัน |
| POST | `/api/bookings/{id}/cancel/` | เจ้าของ / แอดมิน | ยกเลิกและคืนที่นั่ง |
| POST | `/api/bookings/{id}/confirm/` | แอดมิน | ยืนยันการจองหลังตรวจสลิป |
| POST/PUT/PATCH/DELETE | `/api/stations/`, `/api/car-types/`, `/api/trains/`, `/api/schedules/` | แอดมิน | เพิ่ม แก้ ลบข้อมูล |
| POST | `/api/trains/{id}/carriages/` | แอดมิน | เพิ่มตู้ `{"car_type": id}` สร้างที่นั่งตามผังให้อัตโนมัติ |
| POST | `/api/chat/` | ทุกคน | ถามผู้ช่วย AI `{"messages": [{"role": "user", "content": "..."}]}` |

**รหัสสถานะที่ใช้:** `200` สำเร็จ · `201` สร้างแล้ว · `400` ข้อมูลไม่ถูกต้อง · `401/403` ไม่มีสิทธิ์ · `404` ไม่พบ · `409` ที่นั่งถูกจองแล้ว หรือลบไม่ได้เพราะมีข้อมูลอ้างอิง

**ตัวอย่างด้วย curl** (บน Windows ใช้ใน Git Bash หรือใช้ Postman แทนได้)

```bash
# ขอ token
curl -X POST http://127.0.0.1:8000/api/auth/token/ -H "Content-Type: application/json" -d "{\"email\": \"test@railspeed.th\", \"password\": \"Test1234!\"}"

# ค้นหารอบเดินทาง (ใส่ id สถานีจาก /api/stations/)
curl "http://127.0.0.1:8000/api/schedules/?from=1&to=12&date=2026-10-12"

# จองที่นั่ง
curl -X POST http://127.0.0.1:8000/api/bookings/ -H "Authorization: Token <token>" -H "Content-Type: application/json" -d "{\"schedule\": 10, \"seats\": [101, 102]}"
```

## 10. ข้อมูลถูกเก็บที่ไหน

- ข้อมูลทั้งหมดอยู่ในไฟล์ **`db.sqlite3`** สลิปที่อัปโหลดอยู่ในโฟลเดอร์ **`media/slips/`** ปิดเครื่องแล้วข้อมูลยังอยู่
- ทุกอย่างที่แอดมินเพิ่ม แก้ หรือลบ บันทึกลงฐานข้อมูลทันที และมีผลกับฝั่งผู้ใช้ทันที (แก้ราคามีผลกับการจองใหม่เท่านั้น)
- **ระวัง:** `python manage.py seed --reset` จะลบข้อมูลทั้งหมดแล้วสร้างข้อมูลตัวอย่างใหม่ และถ้าลบไฟล์ `db_seeded.flag` สคริปต์ `run_windows.bat` จะ reset ข้อมูลในครั้งถัดไป
- สำรองข้อมูล: ปิดเซิร์ฟเวอร์แล้วคัดลอก `db.sqlite3` และโฟลเดอร์ `media` เก็บไว้
- ดูข้อมูลดิบทุกตาราง: ล็อกอินแอดมินแล้วเข้า http://127.0.0.1:8000/django-admin/

```

booking/api.py             REST API (Django REST Framework)
booking/manage_views.py    หน้าฝั่งแอดมิน
booking/management/commands/seed.py   ข้อมูลตัวอย่าง
railspeed/settings.py      การตั้งค่า (อ่านค่าจากไฟล์ .env)
templates/base.html        header / footer / ปุ่มแชท (ฝั่งผู้ใช้)
templates/manage/base.html sidebar แอดมิน
templates/public/*.html    หน้าฝั่งผู้ใช้ (หน้าหลัก ค้นหา เลือกที่นั่ง ผู้โดยสาร ชำระเงิน ตั๋ว ฯลฯ)
templates/manage/*.html    หน้าฝั่งแอดมิน
templates/partials/head.html  ชุดสีจาก Stitch + ชุดสีโหมดมืด
static/rs/app.js           โหมดมืด เมนู แชท
```
